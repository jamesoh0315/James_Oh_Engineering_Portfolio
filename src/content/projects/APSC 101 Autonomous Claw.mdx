This is a first-year engineering project at the **University of British Columbia**, built for
**APSC 101 — Introduction to Engineering II**. The claw hangs from a line and closes on its
own: an ultrasonic sensor watches the gap underneath it, and the servo fires once the
object is close enough.

## Overview
### Design Objectives

- **Flexibility** — Grab and hold a variety of items across different sizes, weights, and
  dimensions, rather than one part in one orientation.
- **Efficient code** — Make the claw time efficient by giving it a precise script to follow,
  built around an Arduino controller and a sonar sensor.
- **Durability** — A claw body and motorizing mechanism durable enough to survive repeated
  use and minor collisions.

## Design overview

The trigger is a single ultrasonic distance sensor. It measures the gap between the claw and
whatever is beneath it, and once that gap holds under the threshold, the servo closes the
jaws.

Two details in the code did most of the work for reliability. The jaws close through a
`for` loop that steps the servo down in 2° increments with a short delay between each, so
they draw shut at a controlled rate instead of slamming closed and knocking the object away.

The sensor reading is **debounced**. A single close reading is not enough to fire.
The distance has to stay under the trigger threshold continuously for a set interval before
the claw commits, which rejects the erroneous spikes an ultrasonic sensor throws when it
catches an edge or misses a return entirely.

## CAD prototype

The claw was designed in **SolidWorks**, with imported models for the sensor and the
Arduino and the rest of the body built using **sheet metal** features so it could be
flattened, cut, and bent from aluminium.

## Outcome

The claw exceeded expectations, picking up **38 blocks** in a timed class competition.
The claw set the class record and won us the competition, demonstrating excellent
reliability and efficiency.
